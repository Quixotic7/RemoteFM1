# FIZZ's RemoteFM1 skin

The skin tools/rfm1/build_fizz.sh adds to fizz-<version>.rfm1 (RemoteFM1IOS docs/RFM1-FORMAT.md section 8): the
owner's colourway (magenta faceplate, violet keys, dark purple knobs, lime LEDs: all fourteen roles in theme.json) over
cosmic light rays at 30 degrees from vertical, drawn in code (no photo, no outside art). `dim` is the faceplate tint
over the image.
