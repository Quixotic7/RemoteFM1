# RemoteFM1 standalone: LATCH (the owner, 2026-10-30). LFO held toggles it (tapped, LFO is still CC bank D); the notes
# played stay after the keys are let go; keys added while one is held join the chord; a key down when none is held
# replaces the chord; with the arp, the arp keeps stepping the latched keys; LATCH off lets the notes go; LFO blinks,
# the HOME views show a LATCH chip. tests/run_tests.sh runs it (both builds).
