RemoteFM1 for the SMK-37test

RemoteFM1 on the M-Vave SMK-37 Pro, SMK-37 Elite and MKE-P37 (the Starrykey 37 Play takes the Pro's package). To every host the keyboard is an FM-1: it plays this site's player, the iOS app and FM1VST as their panel, and on its own it is RemoteFM1's DX7. Try the controls first in the emulator: this build's own code on an SMK-37 Pro's panel, in your browser.

Before you install

  • This build has not run on an SMK-37. Nobody on the project has one: it follows genkigenki's porting guide and passes the simulator's tests, nothing more. It may not start, or not work as described.
  • Have the way back at hand: M-Vave's stock package for your model and their updater, M-UPGRADE. A full flash backup first is the porting guide's advice (the calibration and the Bluetooth and key data are the unit's own).
  • The first start clears another firmware's data in RemoteFM1's flash areas (ChoralRoot's on the SMK-37 among them: back it up first). The calibration, the Bluetooth pairing and the key areas are never written.
  • Chrome or Edge on a computer, the keyboard connected directly by a USB data cable. Close every app that uses MIDI. Keep it connected until it has restarted. Installing other firmware is at your own risk.

This browser has no Web MIDI: open this page in Chrome or Edge.

Install

RemoteFM1 … for the SMK-37, built …. The page picks your model's package from the keyboard's answer and checks its SHA-256 before it writes.

    The install did not finish

    Switch the keyboard on again (hold OCTAVE- while switching on if it does not come up in update mode) and press Install again: it finishes the write. To give up, install M-Vave's stock package for your model with M-UPGRADE.

    RemoteFM1 is installed

    The keyboard restarts into RemoteFM1's splash and its waiting screen. Try it on its own, then with the player, and tell us what you find: what to test, and the issues.

    Testing it
    
    
    SMK37.md, What to test
      lists what only a unit can answer, in order: the first start, the keys, the pads, the knobs, the buttons and their
      lights, the wheels and the pedal, the faders, a host, USB audio, saving, going back. Note your model, the package
      and what you saw; a photo of the screen or the pads helps. The controls
      map the SMK-37's keys, pads, knobs and buttons onto the FM-1's.
    
  
    

  
    
    
    If an install is cut off
    
    
    Switch the keyboard off and on (hold OCTAVE- while switching on if it does not come up in update mode),
      open this page and press Install again: it finds RemoteFM1's update mode and finishes the write with your
      model's package. Another firmware's update mode (M-UPGRADE's among them) is left to its own updater.
    
  
    

  
    
    
    Going back
    
    
    Install M-Vave's stock package for your model with M-UPGRADE. RemoteFM1 answers with the model's
      identity (SMK-37 Pro_52000301, SMK-37 Elite_52000301, MKE-P37_52000301)
      and takes the stock package. The calibration, the Bluetooth pairing and the key areas were never written; the
      stock firmware's key, knob and fader mapping is as it was, or its factory one if RemoteFM1 saved into its area.
      On RemoteFM1, OCTAVE- held at power-on enters the chip's update mode.
