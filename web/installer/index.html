Install RemoteFM1

RemoteFM1 turns the M-VAVE FM-1 into a panel, over USB or Bluetooth MIDI. Its keys, buttons, knobs and MASTER go to the computer, and the computer draws its screen and lights its LEDs. It makes no sound on its own: a firmware running on the computer plays, in this site's player, in FM1VST or in fm1remote, and over USB the computer can play through the FM-1's speaker or headphones.

Before you start

ChoralRoot users: back up first with ChoralRoot's own page (its installer's Back up button). RemoteFM1 reads and writes nothing of what ChoralRoot keeps, and ChoralRoot finds it all when you go back; a backup costs a minute and covers the unexpected.

Close every app that uses MIDI: DAWs (Ableton Live, Logic, ...), synth editors, and other browser tabs with an FM-1 page. An app sending MIDI clock to the FM-1 can stall an install halfway.

Chrome or Edge on a computer: installing needs Web MIDI with SysEx. The FM-1 charged, switched on and connected with a USB data cable, directly. Installing firmware is at your own risk.

This browser has no Web MIDI: open this page in Chrome or Edge.

Install

RemoteFM1 …, released …. SHA-256 …

    Open the player: your FM-1 connects automatically

    This page was just allowed MIDI, and the player is on the same site, so it finds the FM-1 by itself once it shows REMOTE FM1 / WAITING FOR HOST (a few seconds after the restart).

    Open the player

    If it doesn't connect: check the FM-1 shows REMOTE FM1 / WAITING FOR HOST, then press Connect FM-1 at the top of the player (or Play on my FM-1), and allow MIDI if Chrome asks.

    Log
    
  
    

  
    
    
    Then
    
    
    The FM-1 restarts showing REMOTE FM1 / WAITING FOR HOST, its key lights dim. Open the
      player in Chrome or Edge: once MIDI is allowed for this site, it connects to the FM-1 by itself (the
      Connect FM-1 button at its top shows the state; press it if it stays grey). Pick a firmware and press Play.
      On a Mac, fm1remote and FM1VST use it too (how).
    
    
    Without a cable (the USB + Bluetooth package): connect the FM-1 as a Bluetooth MIDI device (on a Mac: Audio
      MIDI Setup > MIDI Studio > Bluetooth). Its name, "FM-1" and four characters, is on its waiting screen. The
      screen is slower that way. Installing always goes over USB.
    
    
    Sound on the FM-1: over USB the computer sees an audio output named "FM-1"; pick it, and the FM-1's speaker
      or headphones play, with MASTER as the volume.
    
  
    

  
    
    
    If an install is cut off
    
    
    A pulled cable or a flat battery is not the end: switch the FM-1 off and on. It comes back in update mode:
      a black screen (three short flashes of the key lights), or UPDATING / DO NOT UNPLUG, depending on the firmware it
      was leaving. Open this page (or the installer you were using) and press Install again with the same
      firmware: it finishes the write.
    
    
    Leaving RemoteFM1 0.1, ChoralRoot or TransitFM1: do not switch off and on twice in a row while it is
      in update mode: the second time it drops into the chip's own USB boot ("WL82 UBOOT1.00"), where
      MvaveFM1Unbricker (Windows or Linux) or the
      FM-1 Transporter take over. Arriving from the official
      V15, a cut-off write ends there rather than in update mode. On RemoteFM1 0.2, holding REC while switching on
      enters that USB boot on purpose (0.1: OCT-, its own update mode).
    
  
    

  
    
    
    Leaving RemoteFM1
    
    
    Install the next firmware with its own installer, as you would over the official firmware. RemoteFM1 0.2
      answers installers as itself (FM-1_52000301 for 0.3.1, USB device "FM-1"; 0.1 answered as V15,
      FM-1_015). An installer that does not know it yet may refuse it: then install that firmware's
      .fwsc from here (below). RemoteFM1 writes the next firmware with its own update loader. To go back to
      stock, install M-VAVE's official V15 FM-1.fwsc (below); to go on to V16, update from V15 with M-VAVE's
      M-UPGRADE.
    
    
    M-VAVE's V16, Baud Girl, and any firmware whose image is larger than the app area: install the
      official V15 first, then that firmware from V15 with its own installer (V16: M-VAVE's M-UPGRADE).
    
    
    
      Install a package file from here
      
    An FM-1 package (.fwsc), for example M-VAVE's FM-1.fwsc or the release of the
        firmware you are going to. Also finishes a cut-off install of that file.
