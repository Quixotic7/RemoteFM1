Licences

RemoteFM1's firmware is MPL-2.0 from 0.2 (MPL-2.0.txt), built on fm1-base and felucca-bsp; 0.1.1 is GPL-3.0-only (LICENSE). Source: https://github.com/Quixotic7/RemoteFM1, at each release's tag (./build.sh --release 0.2.2, with --no-ble for the USB-only package). The USB + Bluetooth package links JieLi's Bluetooth library (Apache-2.0). Every package holds three files of the JieLi AC79 SDK (Apache-2.0) and a font (OFL-1.1). LICENSING.md says which is where.
